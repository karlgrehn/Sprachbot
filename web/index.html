Iris

Ein persönlicher Agent. Ein einziges Textfeld steuert alles.

Eine Datei, alles enthalten. Keine weitere Installation nötig.

Herunterladen
Android, iPhone oder ein weiterer Rechner? Kein Download nötig — Iris läuft dort als Web-App, verbunden mit dem Rechner, auf dem die Installation oben läuft. Einrichtung (Tailscale) steht im Handbuch, das der Installation beiliegt.

Läuft nach der Einrichtung lokal, ohne dass Nachrichten oder Daten einen fremden Server erreichen.
